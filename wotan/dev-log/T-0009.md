# T-0009: Preserve DrawingML shapes (textboxes, shapes, SmartArt) on round-trip

**Status**: DONE | **Size**: L
**Phase**: —

## Context
DrawingML shapes (textboxes, freeform shapes, SmartArt, connectors) are the last major feature class that gets LOST when an XLSX file is round-tripped through openpyxl. The current drawing reader only processes charts and images; all other drawing content is silently dropped.

## Acceptance Criteria
- [x] Identify all DrawingML element types currently lost on round-trip
- [x] Shapes (sp), group shapes (grpSp), connectors (cxnSp) survive round-trip
- [x] Textboxes with text content survive round-trip
- [x] SmartArt references survive round-trip (binary preservation acceptable)
- [x] Existing chart and image handling is not broken
- [x] Round-trip test with programmatically-injected drawing XML
- [x] Full regression suite passes

## Implementation Notes

### Approach: Anchor-Level Raw XML Preservation

Shape-containing anchors are preserved as raw XML elements within SpreadsheetDrawing. Charts and images continue to use the existing fully-parsed model; shapes are opaque blobs.

### Files Modified
- `reader/drawings.py` — Added `_collect_shape_anchors()` that identifies shape-containing anchors in raw drawing XML. `find_images()` now returns 3-tuple `(charts, images, shape_anchors)`.
- `drawing/spreadsheet_drawing.py` — Added `preserved_anchors` list. Updated `__bool__` and `_write()`.
- `worksheet/worksheet.py` — Added `_preserved_drawing_anchors` storage.
- `reader/excel.py` — Updated callers to unpack 3-tuple, store shape anchors on worksheet.
- `writer/excel.py` — Transfer preserved anchors to SpreadsheetDrawing.
- `drawing/properties.py` — Fixed pre-existing `txBax` typo bug in `__elements__`.
- `drawing/connector.py` — Fixed pre-existing `Shape.spPr` allow_none bug in from_tree fallback.

### Tests Added
6 new round-trip tests in `TestShapePreservation`:
- `test_shapes_survive_roundtrip` — sp with prstGeom and txBody
- `test_connector_survives_roundtrip` — cxnSp
- `test_group_shape_survives_roundtrip` — grpSp with sub-shapes
- `test_shapes_coexist_with_images_roundtrip` — mixed shape + image drawing
- `test_shape_drawing_xml_fidelity` — text content verification
- `test_worksheet_data_unaffected_by_shapes` — cell data integrity
